# 受控生成与局部修改

## 选择方法

| 任务 | 优先方式 | 原因 |
|---|---|---|
| 新隐喻、新轮廓、新气质 | 图像生成探索 | 需要视觉发散 |
| 精确比例、位置、连接、遮挡 | 矢量/程序/图像编辑 | 可验证且不漂移 |
| 只换嘴、眼、局部色块 | 局部蒙版或确定性合成 | 保住其余像素 |
| 材质方向尚不明确 | 先生成少量方向样张 | 用于判断而非替换母版 |
| 已确认母形上的统一材质 | 依据母版遮罩确定性处理 | 多方案一致、几何稳定 |
| 生产矢量 | Figma/Illustrator 等真实路径重建 | 位图生成不能替代 |

## 提示词结构

```text
产品常量：产品、用户、价值、使用位置
方向常量：母形、正负形、比例、视觉语言
本轮变量：只改变什么、改变到什么程度
禁改项：必须逐项保持什么
输出条件：画布、背景、尺寸、是否透明、是否只输出对象
负面约束：禁止新增、禁止材质、禁止风格漂移
```

参考图同时存在时，为每张定义角色：`geometry`、`material`、`color`、`composition`、`context` 或 `do-not-copy`。不要用“参考这张图”混合多个目的。

## 局部反馈协议

将自然语言改写成：

```text
对象：当前版本与文件
改动：部位、方向、幅度
保留：轮廓、比例、位置、背景、颜色等
禁止：不可新增或影响的内容
验证：大图、像素差异、小尺寸、场景
```

示例：

> 对象：已确认星星弹出方案；改动：仅把白色弧形嘴替换为居中的倒置圆角三角；保留：星星尺寸、连接深度、底座、两侧短槽、画布；禁止：眼睛、材质、阴影和额外符号；验证：补丁外像素差异为零，查看 24/32/48/64 px。

## 失败处理

- 模型改变禁改区域：不要继续修补，回到母版。
- 看似局部但源图不可分层：先建立遮罩或重建局部，不假称无损。
- 变化太轻不可见：在不引入新层级的前提下增加色值或面积差异。
- 质感压过造型：删除高光、阴影、噪声和厚边，回到平面母形。
- 只改颜色却发生轮廓漂移：标为探索稿，不能替换确认版本。

## 记录

每次输出记录真实工具和模型；未知就写未知。记录完整提示词、输入参考及用途、输出 SHA-256、实际像素和视觉观察。程序合成记录脚本与母版哈希。
