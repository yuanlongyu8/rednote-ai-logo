# 小红书产品 Logo 的设计取向

## 依据与优先级

1. 用户于 2026-09-17 提供的“小红书产品设计原则”截图：中心为清晰 Clarity；简约 Minimalism、一致 Consistency、易用 Usability、灵动 Flexibility；左侧稳定/可靠/友善，右侧年轻/有趣/活力。这是用户提供的材料，未核验版本与完整官方规范。
2. Spark 项目中的多轮明确要求：避免重科技、写实、直白且缺乏辨识度的语言；材质和颜色必须克制。部分黑色主体明确禁止渐变，部分背景与浅色键帽允许轻微明暗变化。不能把某一轮“禁渐变”扩大成小红书所有 Logo 的官方规则。
3. 组长方法：产品文档提词 → 基础图形表达品牌含义 → 外层修饰与呈现。不是先套键帽材质再为 S 编故事。
4. 公开参考仅辅助理解：[REDesign 官方作品](https://www.behance.net/redesignb4b3)、[2022 设计周团队说明](https://www.digitaling.com/projects/237726.html)。活动的实验性不直接等同于产品图标规范。不得把推断写成官方条款。

## 把原则变成设计判断

| 原则 | Logo 中的执行 | 退回修改的信号 |
|---|---|---|
| 清晰 | 第一眼识别一个主体；解释说明只补充第二层含义 | 要读一段故事才能知道画的是什么 |
| 简约 | 一个核心意象、一个有意义的变化；去掉无关装饰 | 火焰、S、气泡、星芒、键盘层层叠加 |
| 一致 | 同一母形跨单色、反白、色块、尺寸保持身份 | 不同配色变成不同轮廓、圆角各说各话 |
| 易用 | 实际 24/32/48/64 px 看轮廓与正负形；标志与背景对比足够 | 缝隙闭合、表情失效、依赖光效才看得清 |
| 灵动 | 用比例、姿态、节奏或有意的不对称制造一个记忆点 | 普通圆角方框加两只眼睛；随机歪斜装可爱 |
| 可靠且友善 | 稳定重心、干净边界、不尖锐逼人 | 冷硬设备感、脏噪声、过多薄线 |
| 年轻且有趣 | 从产品行为生出小巧思，不等于幼态 | 通用 AI 星星、机器人、字母图标换皮 |

“清楚”与“直白”不同：轮廓需要看得懂，但不必画完整键盘，也不能只写首字母。辨识度来自特定轮廓或正负形关系，不来自更复杂的渲染。

## 两层流程与停点

A 基础形：提取产品事实及出处，另列隐喻。用黑白探索有语义的轮廓。讲清“主体是什么—哪一个细节独特—与产品关系—容易误读成什么”。设计师未确认时停在形状评审，不扩几十套颜色。

B 呈现：固定已选母形，对比平面与轻键帽。优先少量纯色色面、细窄边缘和轻微明度差。渐变不是默认答案；只有用户明确允许、能解释层级且不改变基础关系时才使用，范围与强度都要受控。避免镜面、重金属、霓虹、光晕、颗粒、大阴影或照片级塑料。若无法不靠强效果实现轻拟物，退回平面。

配色在母形确认后开展：少量颜色明确分工；不强制红色，也不以蓝紫定义智能。黑白版须重构正负层次，不是把全部涂黑。历史渐变稿可归档展示，但不能未经判断成为新候选默认值。

## 分工与验收边界

程序负责相同尺寸场景、版本与资产完整性；可发现代码中显式渐变，但不能据此证明位图无渐变，更不能自动评定品牌品味。Agent 必须看图检查材质与上述退回信号；设计师决定含义是否成立、是否有个性及最终选择。任何机械 PASS 都不等于调性通过。
