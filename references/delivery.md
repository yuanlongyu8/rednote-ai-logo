# 生产交付

## 评审资产与生产资产

| 资产 | 可以证明 | 不能证明 |
|---|---|---|
| 生成 PNG | 视觉方向存在 | 几何可编辑、可生产 |
| HTML 组合图 | 场景和比较关系 | 原生图层或矢量 |
| Figma 图片填充 | 已进入目标文件 | Logo 已矢量化 |
| SVG 包含 `<image>` | 可作为容器显示 | 真正矢量母版 |
| 灰度滤镜 | 灰度预览 | 生产单色结构成立 |
| 人工重建 SVG | 路径可编辑 | 所有品牌/法律风险已通过 |

## 最低生产包

- 可编辑矢量母版；
- 1024 px 与必要平台尺寸 PNG；
- 彩色、单色、反白版本；
- 24/32 px 等需要的光学修正版；
- App icon 与独立图形标的适配关系；
- 最小尺寸、安全区、色值和背景禁例；
- 字标、字体/字形授权说明；
- 相似性检索和法律检查状态；
- 与最终人工确认版本的差异记录。

## 交付检查

- 路径无多余锚点、开放路径、不可解释遮罩或嵌入位图；
- 负形和连接关系在导出后不漂移；
- 透明边缘无脏像素、白边和光晕；
- 深浅背景、打印和低质量媒介中仍可辨认；
- 文件命名、版本、哈希和确认记录一致；
- 未完成项明确为 pending，不写成 PASS。
